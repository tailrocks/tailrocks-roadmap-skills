# Runtime requirements

Install the [complete package](installation.md). The native registrars only
register skill files. Skill procedures control when to call tools or execute a
script. Installation grants no authority for a skill action.

Delivery workflows need Git. For a GitHub.com pull request, use an
authenticated `gh` session with the required repository permissions. Read-only
work can run without that authentication. Keep the templates and references
with each skill.
